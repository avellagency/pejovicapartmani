# Pejović apartmani Mojkovac

Statički sajt za GitHub Pages.

1. Uploadujte sadržaj ovog foldera u repo (root).
2. Settings → Pages → Branch: main / root.
3. Zamijenite `https://pejovic-apartmani.github.io/` pravim domenom u svim .html fajlovima, robots.txt i sitemap.xml.
5. Cijene: rezervacija.html → PRICE_PER_NIGHT, CLEANING_FEE, MIN_NIGHTS, BOOKED_DATES.
